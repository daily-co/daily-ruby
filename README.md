## Documentation for Authorization

Every request sends your Daily API key as a Bearer token:
`Authorization: Bearer <your API key>`.

Since 1.1.0 the spec calls this scheme `bearerAuth`. The new way to set the key:

```ruby
Daily.configure do |config|
  config.access_token = 'YOUR_DAILY_API_KEY'
  # Or pass a proc that returns the key each time:
  # config.access_token_getter = -> { fetch_key_from_vault }
end
```

The old 1.0.x style still works, so you do not need to change existing code:

```ruby
Daily.configure do |config|
  config.api_key['sec0'] = 'YOUR_DAILY_API_KEY'
  config.api_key_prefix['sec0'] = 'Bearer' # optional, Bearer is added if missing
end
```

If both are set, `access_token` wins. See `lib/daily-ruby/compat.rb` and
`CHANGELOG.md` for the other things kept for 1.0.x callers.
